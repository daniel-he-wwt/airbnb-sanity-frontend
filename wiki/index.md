# airbnb-sanity-frontend wiki

Project pages for the Next.js + Sanity.io Airbnb clone frontend. Shared conventions are in the global wiki (`wwt/aine-forge-starter-c12-daniel-he-wwt`, `wiki/global/`).

- [coding-standards.md](coding-standards.md) — Stack versions, formatting style, naming, folder layout, Sanity/GROQ usage, logging, testing and review checklist.
- [architecture-decisions.md](architecture-decisions.md) — Reconstructed ADRs: Sanity headless CMS, a single sanity.js client, SSR with getServerSideProps, global CSS, Google Maps.
- [known-issues.md](known-issues.md) — Known bugs and gotchas: Maps API key env var, crashes on empty or incomplete data, map bounds and no clustering, React keys, old dependencies.
