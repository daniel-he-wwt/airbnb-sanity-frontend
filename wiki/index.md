# airbnb-sanity-frontend wiki

Project pages for the Next.js + Sanity.io AirBnB clone frontend. Shared conventions live in the global wiki (wwt/aine-forge-starter-c12-daniel-he-wwt, wiki/global/).

- [coding-standards.md](coding-standards.md) — JS/Next.js conventions: formatting, naming, folder layout, Sanity data access, logging, testing and review expectations.
- [architecture-decisions.md](architecture-decisions.md) — Reconstructed ADRs: Sanity via next-sanity, SSR with GROQ, shared _app layout, global CSS, Google Maps components.
- [known-issues.md](known-issues.md) — Bugs and gotchas found in the code: Maps API key env var, empty/missing data crashes, missing React keys, fitBounds, debug logs, outdated deps.
