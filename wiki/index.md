# Wiki index

Project wiki for `airbnb-sanity-frontend`, a Next.js + Sanity.io AirBnB clone. Shared pages are in the global wiki (`wwt/aine-forge-starter-c12-daniel-he-wwt`, `wiki/global/`).

- [coding-standards.md](coding-standards.md) — Code style, naming, project layout, Sanity/GROQ usage, error handling, testing and review rules for this Next.js frontend.
- [architecture-decisions.md](architecture-decisions.md) — Decisions taken from the code: Next.js pages router, Sanity CMS with GROQ, SSR via getServerSideProps, global CSS, Google Maps components.
- [known-issues.md](known-issues.md) — Known bugs and workarounds: Maps API key env var, crashes on empty or missing data, fitBounds, React key warnings, performance and outdated dependencies.
